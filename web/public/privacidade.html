Daily Hub: política de privacidade

O Daily Hub é uma app pessoal, usada apenas pelo seu autor.

  • Acede ao Gmail e ao Google Calendar só em modo de leitura, para preparar um resumo diário.
  • Do email, só o assunto e um excerto são usados, depois de um filtro que oculta dados pessoais e clínicos.
  • Os dados não são vendidos, partilhados com terceiros nem usados para publicidade.
  • O resumo fica guardado numa base de dados privada, acessível apenas ao autor.

O uso de dados obtidos através das APIs Google cumpre a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
